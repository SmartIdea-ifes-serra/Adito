## Historia

**Como** Engenheiro de Dados
**Eu quero** definir as tabelas de banco de dados (`acao`, `atividade`, `pessoa`, `participacao`) usando SQLAlchemy ORM
**Para que** o pipeline ETL possa armazenar dados relacionais normalizados, prevenindo redundâncias e viabilizando integrações futuras.

### Contexto Adicional

Atualmente, o projeto gera arquivos JSON. Precisamos da fundação do banco de dados relacional para migrar a saída. A modelagem deve respeitar o `DICIONARIO_DADOS_SRC.md`.
