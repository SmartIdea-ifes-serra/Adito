# Assumptions

Registro central de suposicoes e decisoes adiadas usadas durante refinamento, especificacao ou implementacao.

## Como usar

- Registre aqui assumptions que impactam codigo, Spec, BDD ou rollout
- Quando a suposicao for confirmada, atualize o status
- Quando a assumption virar regra permanente, leve a decisao para a Spec, `docs/context.md` ou ADR
