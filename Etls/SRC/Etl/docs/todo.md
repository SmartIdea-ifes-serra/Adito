## Como usar

- Ao iniciar uma tarefa, mova para `Em andamento`
- Se a tarefa implementar uma US, preencha a coluna `US`
- Se houver Spec governada, preencha `Spec`
- Se houver Contract governado, preencha `Contract`
- Se houver BDD aplicavel, preencha `BDD`
- Se nao houver Spec ou Contract governados, use `US nao exige Spec` e `US nao exige Contract`
- Ao concluir, atualize status, PR e observacoes
